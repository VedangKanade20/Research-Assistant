# Frontend Architecture & Implementation Guide

This guide documents the frontend architecture, page routes, state management, and UI component design system of the **AI Research Assistant** application.

---

## 🎨 1. Design System & Tech Stack

* **Framework**: Next.js 14 App Router
* **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
* **Typography**: Modern sans-serif system fonts with HSL dark mode slate/indigo palettes
* **Icons**: `lucide-react`
* **State Management**: React Context API (`AuthContext.js`)

## 🔐 3. Authentication & Session Flow (`AuthContext.js`)

The `AuthProvider` wraps the entire Next.js application in `app/layout.js`.

1. **App Startup Verification**:
   Upon initial page load, `AuthContext.js` checks `localStorage` for a stored JWT token. If present, it executes a validation request against `GET /api/v1/auth/me`.
2. **Login & Register**:
   - `login(email, password)`: Sends POST to `/api/v1/auth/login`, saves token, updates user state, and redirects to `/dashboard`.
   - `logout()`: Clears token from `localStorage` and redirects to `/login`.
3. **Protected Route Protection**:
   If an unauthenticated user attempts to access `/dashboard` or `/documents`, `AuthContext.js` immediately redirects them to `/login`.

## 💬 4. Interactive Split-Screen Chat PDF Workspace (`/documents/[id]`)

Located at [app/(dashboard)/documents/[id]/page.js](file:///d:/Everything/ZZZ-TASKS/resarch-assistant/frontend/app/%28dashboard%29/documents/%5Bid%5D/page.js):

### Left Panel (Document Reader & Summary)
* **Metadata Header**: Displays filename, file type badge, and file size.
* **Executive AI Summary Card**: Highlighted card rendering the 3-4 sentence summary generated by `gemini-3.6-flash`.
* **Extracted Document Reader**: Scrollable container displaying the raw text parsed from the document.

### Right Panel (Interactive RAG Chat Room)
* **Message Feed**: Chronological list of user prompts and AI assistant answers.
* **Token Usage Badge**: Displays exact tokens consumed per response turn.
* **Question Form**: Input bar allowing users to ask questions grounded in the document context.

## 🚀 5. Pagination & UI Controls

* **Document Table Pagination**: Slices document arrays into pages of 5 items with `ChevronLeft` and `ChevronRight` controls.
* **Optimistic State Updates**: Deleting a document immediately removes it from local React state before the server confirmation returns for maximum UI responsiveness.
